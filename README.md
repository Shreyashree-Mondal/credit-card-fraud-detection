# Credit Card Fraud Detection

Anomaly detection project comparing CBLOF, K-Means, and LOF for identifying potentially fraudulent credit-card transactions.

## Tools

- Python
- scikit-learn
- PyOD
- Pandas
- NumPy

## Methods

- CBLOF
- K-Means
- LOF

## Results

CBLOF achieved 97.75% accuracy and 70% recall.
